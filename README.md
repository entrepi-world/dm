# mitochondria-claude-skeleton

Next.js (App Router) + Tailwind project, pre-wired for Vercel.

## Run locally (optional)
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel dashboard: New Project → Import your repo → Framework auto-detects Next.js → Deploy.
3. Done. You get https://<project>.vercel.app

Open `app/page.tsx` and replace with your Claude code.
